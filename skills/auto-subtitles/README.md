# 🎬 Auto-Subtitles — Claude Code Skill



> Авто-субтитры из голоса для любого вертикального/горизонтального/квадратного видео. Whisper → smart-chunks → прожиг с твоим шрифтом и плашкой. Одной командой.

Скилл для [Claude Code](https://www.anthropic.com/claude-code), который превращает любое видео с голосом в видео с **аккуратными прожжёнными субтитрами**: Whisper распознаёт речь с пословными таймштампами, скилл умно режет на куски 2-5 слов по пунктуации и паузам, и ffmpeg прожигает их с твоим шрифтом и брендовой плашкой.

🇬🇧 [English version](./README.en.md)

---

## Зачем

CapCut и Premiere **не сохраняют стили из .srt/.ass файлов** — субтитры приходят голым Arial. Чтобы получить брендовые субтитры на 38 видео, нужно либо платить редактору 38 часов, либо смотреть, как нейронка делает за 10 минут.

Этот скилл — второй вариант. Точные тайминги, осмысленные чанки, любой шрифт, любые цвета.

---

## Что умеет

- ✅ Распознаёт речь Whisper `large-v3` — лучшая модель, **95-99% точность**
- ✅ **Пословные таймштампы** — субтитры идут синхронно с голосом, без сдвигов
- ✅ **Smart-chunking** — режет на 2-5 слов по пунктуации и паузам, не строгими блоками
- ✅ **Фильтр галлюцинаций** — убирает «Субтитры подготовил DimaTorzok» и подобный мусор Whisper
- ✅ **Любой шрифт** — .otf/.ttf файлы из любой папки
- ✅ **Любая палитра** — цвет текста, плашки, обводки настраиваются
- ✅ **Любой формат кадра** — 9:16 / 16:9 / 1:1, с готовыми пресетами размера шрифта
- ✅ **Любой язык** — всё что поддерживает Whisper (ru, en, es, fr, de, zh, +90 ещё)
- ✅ **Glossary** — передаёшь Claude список имён/брендов/терминов, Whisper их не перепутает

## Установка

1. Скилл:

```bash
mkdir -p ~/.claude/skills/auto-subtitles
curl -fsSL https://raw.githubusercontent.com/sketch-man/claude-skill-auto-subtitles/main/SKILL.md \
  -o ~/.claude/skills/auto-subtitles/SKILL.md
```

2. Зависимости:

```bash
# macOS Apple Silicon (быстро, рекомендуется)
pip install mlx-whisper
brew install ffmpeg

# Linux/Windows
pip install openai-whisper
# ffmpeg: apt install ffmpeg / scoop install ffmpeg
```

3. Перезапусти Claude Code. Скилл подхватится автоматически.

## Как пользоваться

Открой Claude Code в папке с видео и опиши задачу:

```
Сделай авто-субтитры на все видео в папке.
Шрифт: /Users/me/fonts/Inter-Bold.otf
Цвета: текст белый, плашка тёмно-синяя rgba(20,30,60,0.7)
Формат: 9:16
Язык: русский
Брендовые слова: Сибур, Вивилен, ПЭТ
```

Claude:
1. Запустит Whisper large-v3 на каждом видео
2. Получит JSON с пословными таймштампами
3. Нарежет на смысловые чанки 2-5 слов
4. Сгенерирует ASS с твоим стилем
5. ffmpeg прожжёт субтитры в видео
6. Сложит результаты в `out/`

На M1/M2/M3 → ~30-60 сек на минуту видео.

## Параметры конфигурации

Все настройки внутри `SKILL.md` и в Python-скрипте, который Claude генерирует:

| Параметр | Что | Дефолт для 9:16 |
|---|---|---|
| `FONT_NAME` | Имя шрифта (должно совпадать с файлом в `FONTS_DIR`) | — |
| `FONT_SIZE` | Размер шрифта в pt | 60 |
| `FONTS_DIR` | Папка со шрифтами `.otf`/`.ttf` | — |
| `STRIP_Y` | Позиция плашки от верха видео, px | 140 |
| `STRIP_H` | Высота плашки, px | 140 |
| `PLATE_COLOR` | Цвет плашки (ffmpeg) | `black@0.55` |
| `TEXT_COLOR` | Цвет текста (ASS BGR hex) | `&H00FFFFFF` (белый) |
| `MIN_WORDS` / `MAX_WORDS` | Слов в чанке | 2 / 5 |
| `MAX_CHARS` | Максимум символов в чанке | 32 |
| `PAUSE_THRESHOLD` | Пауза для разрыва, сек | 0.40 |
